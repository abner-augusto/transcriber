## Findings considered and rejected

- Installing whichever Transformers release is newest at startup: rejected
  because it makes each machine and reinstall a different runtime.
- Treating the Qwen forced aligner as mandatory for VibeVoice: rejected because
  the existing adapter already defines proportional timestamps as a deliberate
  fallback and native diarization does not depend on that aligner.
- Loading every 7B model whenever the Settings screen opens: rejected because a
  health check must remain fast and must not allocate several gigabytes of VRAM.
- Containers per Engine as the first isolation mechanism: deferred. Native
  subprocess runtimes fit the existing local Windows/GPU deployment with less
  operational change; containers can be reconsidered for Linux deployment.
